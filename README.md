# Radial Wheel · 轮盘快捷键

Minecraft **26.2** / Fabric 客户端模组。**一个轮盘 + 多页 + 图标**，不搞多轮盘。

按住一个功能键弹出轮盘，鼠标指向扇区后**松开按键**即可触发；轮盘打开时**滚轮切换页面**。
每个扇区可以：

- **快捷键**：触发任意一个已注册的按键绑定（原版的，或任何模组注册的，包括 masa 系列的 Tweakeroo / Litematica / MiniHUD）
- **指令**：发送一条聊天消息，或执行一条 `/指令`（带原版指令补全）
- **原始按键**：直接模拟「键盘按键 + 鼠标键 + 修饰键」的组合，喂给那些只认原始输入的模组

这样就能把一堆零散的物理快捷键收进一个轮盘，**把键盘按键还给自己**。

> **1.4.0**：去掉轮盘名称与左下角提示，界面重排成三个带标题面板，标签右对齐；**1.3.0 修了一个崩溃**：之前打开轮盘后按右键（进入扇区设置）会因为文字绘制递归而崩
> （日志里是 `IllegalStateException: max stack size of 16 reached`）。本版本已修复。

## 1. 环境要求

| 组件 | 版本 |
| --- | --- |
| Minecraft | 26.2 |
| Fabric Loader | ≥ 0.19.5（最低 0.18.4 也能加载，但强烈建议 0.19.5，见 7.1 / 7.2） |
| Fabric API | ≥ 0.161.0+26.2 |
| Java | 25 |

## 2. 安装

把构建产物 `build/libs/radialwheel-1.4.0.jar` 放进 `.minecraft/mods/`（需要同时安装 Fabric API）。
本模组是**纯客户端**模组，服务器端不需要安装。

> 首次安装生成的轮盘是 **6 个全空的扇区**，不预置任何热键或指令。第一次给某个扇区挑热键时，
> `显示名` 会自动填成该热键的名字（之后你手动改过就不再自动覆盖）。

## 3. 默认操作

| 操作 | 效果 |
| --- | --- |
| **按住触发键** | 打开轮盘（默认 `左Alt`，可在设置里改） |
| 移动鼠标 | 选择扇区；停留在中心死区内 = 取消 |
| **松开触发键** | 触发当前指向的扇区 |
| **鼠标滚轮** | 切换页面（第 1 页 / 第 2 页 …） |
| 鼠标左键点击扇区 | 立即触发（可在设置里关闭） |
| 鼠标右键 | 打开当前指向扇区的设置界面 |
| `ESC` | 取消，不触发 |

另外还有一个 `轮盘：打开设置` 的绑定，默认**未绑定**（不占用你的按键），需要时自己绑，或者用 `/radialwheel`。

## 4. 设置界面

三种打开方式：**轮盘里点右键** / 输入客户端命令 `/radialwheel` / 给「轮盘：打开设置」绑定一个键。

界面一页三栏，每栏一个带标题的面板，标签右对齐、控件左对齐对齐成一列：

```
┌─ 当前扇区 ─────┬─ 页面与触发键 ─┬─ 外观与行为 ───┐
│  扇区  < 1/6 > │  页   < 1/2 >  │ 显示标签   [开] │
│ 类型：  [空  ] │ 页名：[p1   ]  │ 图标模式   [关] │
│ 目标：  [ …  ] │ 新增页 删除页  │ 触发提示   [开] │
│ 显示名：[ …  ] │ 触发键         │ 点击即触发 [开] │
│ 图标：  [ …  ] │  [ left.alt ]  │ 字体随大小 [开] │
│ 注入原始按键   │                │ 字体大小 -100%+ │
│ 按住帧数 - 2 + │                │ 大小     - 92 + │
│ 附加修饰键     │                │ 位置 X/Y / 死区 │
│ Shift Ctrl Alt │                │ 扇区数量        │
└────────────────┴────────────────┴─────────────────┘
```

### 4.1 当前扇区

- `扇区`：用 `<` `>` 切换要编辑的扇区（2–12 个）
- `类型`：循环切换 空 → **热键** → 指令 → 原始按键
- `目标`：
  - **热键** → 点按钮进入分类选择界面（见 4.4），原版快捷键、**其它模组的快捷键**、**masa 系列（malilib）热键**都在里面，不需要手打任何东西
  - 指令 → 输入框，`/` 开头按指令执行（带**原版指令补全**，和命令方块一样），否则按聊天消息发送
  - 原始按键 → 两个输入框：键名（`grave` / `r` / `F6`）+ 鼠标键（`left` / `right` / `middle` / `4`…`8`）
- `显示名`：轮盘上显示的文字，留空则自动取热键名 / 指令内容
- `图标`：物品 id，右边的 `选择…` 打开物品图标选择界面（见 4.5），`手持物品` 直接填当前手持物品
- `注入原始按键`：见第 6 节
- `按住帧数`：按下后保持多少 tick 再松开（默认 2）
- `附加修饰键`：Shift / Ctrl / Alt 开关

### 4.2 页面与触发键

- `页`：用 `<` `>` 切换当前页，轮盘里用**滚轮**切页
- `页名`：显示在轮盘中心下方，留空则显示页码
- `新增页` / `删除页`：至少保留一页
- `触发键`：**只有一个，所有页面共用**。点一下按钮 → 变成「请按一个键…」→ 直接按一个键录入；`ESC` 取消

### 4.3 外观与行为

- `显示标签`：扇区上显示文字
- `图标模式`：开 = 用扇区绑定的物品图标代替文字
- `触发提示`：触发时在物品栏上方显示提示
- `点击即触发`：允许左键点击扇区立即触发
- `字体随大小缩放`：开 = 文字大小跟着轮盘大小一起变；关 = 用下面的 `字体大小` 固定比例（50%–250%）
- `大小`：轮盘外圈半径（40–260），也就是轮盘的尺寸
- `位置 X` / `位置 Y`：轮盘中心在屏幕中的**比例**，0.5 是居中，0.25 靠左，0.75 靠右
- `死区`：中心多大的范围内松手算取消
- `扇区数量`：2–12

### 4.4 热键选择界面（分类列表）

左右两栏，样式对齐原版控制界面：

```
┌ 分类 ────────┬ 热键 ─────────────────────────────┐
│ 移动 (5)     │ 前进               [W]            │
│ 杂项 (11)    │ 潜行               [左Shift]      │
│ Tweakeroo · 通用 (12)      │ 快速左键连点      [未绑定] │
│ Tweakeroo · 功能开关 (96)  │ …                        │
│ JEI (3)      │                                   │
└──────────────┴───────────────────────────────────┘
```

- **分类规则**：按模组分组；**模组自己有分类就再按它的分类细分**（masa 系列用的是 malilib 报出来的分类，例如 Tweakeroo 的
  `通用 / 修复项 / 列表 / 功能开关 / 通用快捷键 / 禁用项`，并且用模组自带的中文翻译），只有一个分类的模组就不再细分。
- **左栏**：鼠标放在左栏 → **滚轮切换分类**（也可以 `←` `→`）；点击直接切。
- **右栏**：滚轮翻页；点击条目即选中并返回。
- **搜索**：跨全部分类过滤（中文名、`key.xxx` 原始名、模组名、按键名），搜索时多出一个「全部匹配」分类。
- **刷新列表**：改动过模组配置或新装模组后点一下重建列表。

### 4.5 物品图标选择界面

`图标` 右边的 `选择…` 打开两栏物品选择界面：左栏是命名空间（`Minecraft 原版` / 各模组），
右栏是带**真实物品图标**的列表，支持搜索、`清空`、`手持物品`。

## 5. 配置文件

路径：`.minecraft/config/radialwheel.json`（首次启动自动生成）

```json
{
  "version": 3,
  "triggerKey": 342,
  "wheels": [
    {
      "name": "主轮盘",
      "posX": 0.5,
      "posY": 0.5,
      "radius": 92.0,
      "deadZone": 22.0,
      "hubRatio": 0.42,
      "showLabels": true,
      "iconMode": false,
      "fontScale": 1.0,
      "fontFollowsRadius": true,
      "feedback": true,
      "clickToActivate": true,
      "sectorCount": 6,
      "pages": [
        {
          "name": "第一页",
          "slots": [
            { "type": "HOTKEY", "keybind": "key.togglePerspective", "label": "视角" },
            { "type": "HOTKEY", "masa": "tweakeroo:tweakFastLeftClick", "label": "快速左键连点" },
            { "type": "COMMAND", "command": "/gamemode creative", "label": "创造模式" },
            { "type": "RAW_INPUT", "rawKey": "grave", "rawMouse": "left", "holdTicks": 2, "label": "Masa 连点" },
            { "type": "EMPTY" },
            { "type": "EMPTY" }
          ]
        }
      ]
    }
  ]
}
```

说明：

- `triggerKey` 是 GLFW 键码（`342` = 左 Alt，`-1` = 未绑定），整个轮盘共用。
- `wheels` 数组里**只保留第一个元素**：多余的部分会在读取时被忽略（旧的多轮盘配置会自动只留第一个）。
- `pages` 是页面数组，每页有自己的 `name` 和 `slots`；`sectorCount` 所有页共用。
- 每个扇区的合法类型：`EMPTY`、`HOTKEY`、`COMMAND`、`RAW_INPUT`。
  旧版（1.0/1.1）的 `KEYBIND` / `MASA_HOTKEY` 会被读取并**自动迁移**成 `HOTKEY`。
- 改完文件后可用 `/radialwheel reload` 热重载，不必重启游戏。

## 6. 怎么把 masa 系列的热键搬进轮盘

关键事实：**malilib（masa 系列）的热键不是原版快捷键**，不会出现在「选项 → 控制」里。
但 malilib 自己维护了一份热键注册表，本模组直接读它（`InputEventHandler.getKeybindManager().getKeybindCategories()`），
所以 masa 的热键会**和其它模组一样出现在分类列表里**，选一下即可。

以「`~` + `TAP` + 左键 = 快速左键连点」为例：

1. 按住轮盘键 → 在指向的扇区上**右键**（直接打开该扇区的设置）→ 把 `类型` 切到 **热键**
2. 点 `目标` → 左栏滚到 **Tweakeroo · 功能开关**（或搜索 `快速左键`）
3. 点中 `快速左键连点` → 显示名自动填成 `快速左键连点`
4. 保存即用；原来的物理热键可以去 Tweakeroo 配置里清掉

> 触发 masa 热键走的是 malilib 自己的回调
> `((KeybindMulti) hotkey.getKeybind()).getCallback().onKeyAction(KeyAction.PRESS, keybind)`，
> 不是伪造按键，所以不受「malilib 每 tick 用真实键盘状态校正」的限制。

### 方式 B：`原始按键` 类型

用于「按键 + 鼠标」组合（例如 `~ + TAP + 左键`）或任意输入：`键名` 填 `grave` / `r` / `F6`，
`鼠标键` 填 `left` / `right` / `middle` / `4`…`8`，需要时打开 Shift / Ctrl / Alt。
触发时会把这一组合作为**真实按键事件**注入游戏（通过已注册的 GLFW 回调）。
注意：malilib 每 tick 会用真实键盘状态校正，所以这只适合「按一下触发」的热键。

### 方式 C：普通模组的快捷键

给注册了原版按键绑定的模组（绝大多数 Fabric 模组）用：类型选 **热键**，在选择界面里按模组名找。
保持 `注入原始按键` 为开：若该快捷键还绑着键，就直接注入那个键的真实事件；若你已经把它解绑（推荐），
就退回原版通道，模拟按下并补一次点击计数，保证 `consumeClick()` 类模组也能触发。

## 7. 排错（真实踩过的坑）

### 7.1 启动报 `Incompatible mods found!`，说本 mod 需要 Fabric Loader 0.19.5

本 mod 的 loader 要求已放宽到 `fabricloader >= 0.18.4`，所以 Loader 0.19.3 也能加载，
但仍然**建议把 Fabric Loader 升到 0.19.5 或更高**，原因见下一条。

### 7.2 多版本 wrapper 类 mod 在旧 Loader 上误报 MC 版本不兼容

像 `gugle-carpet-addition` 这类"一个 jar 里内嵌十几个 MC 版本"的包，在 **Loader 0.19.3 及更早**上，
依赖求解器会挑中版本号最高的内嵌包（`mc26.3-snapshot-3`），于是报
`gca 2.12.6-mc26.3-snapshot-3+build.94 需要 'Minecraft' 的 26.3- 及以上版本`。

**实测结论**：把 Loader 升到 **0.19.5** 后，同一个 jar 会被正确解析成 `gca 2.12.6-mc26.2+build.94` 并正常加载。
所以这类报错的正确修法是**升级 Loader**，不是删 mod。
PCL / PCLCE 里：主界面选中该版本 → **版本设置 → 设置/安装 Loader → 换成 Fabric 0.19.5**。

### 7.3 `原始按键` 里能填什么键名

| 写法 | 例子 |
| --- | --- |
| MC 符号名 | `grave.accent`、`left.alt`、`f6` |
| 常见别名 | `grave`（也就是 `` ` `` 和 `~`）、`lalt`、`lctrl`、`lshift`、`return`、`capslock` |
| MC 序列化形式 | `key.keyboard.f6`、`key.keyboard.96` |
| 数字键码 | `96` |
| GLFW 常量名 | `GLFW_KEY_F6` |

> 26.2 的 `InputConstants.getKey(String)` 只接受 `key.keyboard.<数字>`（直接传 `grave` 会抛 `NumberFormatException`），
> 所以本 mod 自己维护了一份符号名表；设置界面底部会实时显示解析结果。
> 想自检这张表可以跑 `gradle keyProbe`。

### 7.4 界面文字太大 / 输入框太高

设置界面的文字按 0.72 倍绘制、输入框高度固定 14px，就是为了在 GUI 缩放较大（比如 4）时也不至于挤爆。
轮盘本身的文字大小由「字体随大小缩放 / 字体大小」控制。

## 8. 注意事项

- 「注入原始按键」会把该键的完整按键事件喂给游戏：如果这个键在原版里还绑定了别的功能，会一并被触发。
  这正是建议去控制里解绑的原因。
- 轮盘打开期间**不会暂停游戏**，也不会阻塞世界运行。
- 在中心死区内松手 = 取消，不会触发任何东西。
- 未在世界中（主菜单、连接中）不会打开轮盘。
- 只支持一个轮盘；想要「左边一个、右边一个」请等后续版本。

Radial Wheel 1.4.0 for Minecraft 26.2

**Settings screen rework**

- The settings screen is now three titled panels: *Current sector* / *Pages & trigger* / *Look & behaviour*
- Labels are right aligned and inputs are left aligned into one column, so everything lines up
- Input boxes are shorter (14 px) and vertically centred in their row
- Step button values are centred between `-` and `+`
- Row height shrinks automatically so the tallest column never runs into the Done button

**Removed**

- The wheel name field (the wheel hub now shows the hovered sector's name, plus the page name or page number)
- The permanent hint at the bottom left; the raw key name resolution now appears right under the fields it belongs to
- 35 unused translation keys left over from earlier versions

**Requirements**

- Minecraft 26.2, Fabric Loader 0.19.5+ recommended (0.18.4 minimum), Fabric API 0.161.0+26.2, Java 25
- Client side only - the server does not need it

## 简介（一句话）

按住一个键弹出径向轮盘，每个扇区可以触发任意快捷键（含其它模组与 masa 系列）、执行指令或注入原始按键，从而把物理按键还给自己。

## 正文

### 这是什么

Radial Wheel 是一个**纯客户端**的径向菜单模组：按住触发键弹出轮盘，鼠标指向扇区后松开即可触发。
它可以触发的目标有三类：

- **快捷键**：任何已注册的按键绑定 —— 原版的、其它模组的、以及 masa 系列（Tweakeroo / Litematica / MiniHUD）的 malilib 热键
- **指令**：直接执行 `/指令` 或发送聊天内容（带原版指令补全）
- **原始按键**：模拟「键盘按键 + 鼠标键 + 修饰键」组合，喂给那些只认原始输入的模组

解决了什么问题：快捷键越装越多，物理键位不够用；masa 系列的热键又**不会出现在「选项 → 控制」**里，
根本没法统一管理。把它们收进轮盘以后，原先的物理按键可以去控制里解绑，**键盘按键就空出来了**。

### 主要功能

- **单轮盘 + 多页**：一个轮盘最多 12 个扇区，页数不限；轮盘打开时用**滚轮**翻页
- **热键选择界面**：左右两栏、对齐原版控制界面；按模组分组，**模组自己有分类就按它的分类细分**
  （例如 Tweakeroo 的 通用 / 修复项 / 列表 / 功能开关 / 通用快捷键 / 禁用项，用的是模组自带的中文翻译）；
  支持跨分类搜索（中文名、`key.xxx`、模组名、按键名）
- **masa 热键直接可读**：读取 malilib 的热键注册表，走它自己的回调触发，不需要伪造按键
- **物品图标**：每个扇区可绑定物品 id，带真实图标的物品选择界面（左栏模组、右栏物品、可搜索、可取手持物品），
  开启「图标模式」后用图标代替文字
- **外观可调**：轮盘大小、屏幕位置、中心死区、扇区数量、是否显示标签、触发提示、点击即触发、
  字体大小（可固定，也可随轮盘大小同步缩放）
- **编辑顺手**：主界面一页三栏（当前扇区 / 页面与触发键 / 外观与行为），标签右对齐、控件左对齐

### 安装

1. 给 Minecraft 26.2 装 **Fabric Loader 0.19.5 或更高**，并把 **Fabric API** 放进 `mods/`
2. 把 `radialwheel-<版本>.jar` 放进 `.minecraft/mods/`
3. 启动游戏。配置文件在 `.minecraft/config/radialwheel.json`

首次启动是 **6 个全空的扇区**，不预置任何热键或指令。第一次给扇区挑热键时，「显示名」会自动填成该热键的名字。

### 使用

| 操作 | 效果 |
| --- | --- |
| 按住触发键 | 打开轮盘（默认 `左Alt`，可改） |
| 移动鼠标 | 选择扇区，停在中心死区 = 取消 |
| 松开触发键 | 触发当前指向的扇区 |
| 鼠标滚轮 | 切换页面 |
| 鼠标右键 | 打开当前指向扇区的设置 |
| `ESC` | 取消 |

也可以给「轮盘：打开设置」绑定一个键，或者直接用客户端命令 `/radialwheel`。

### 常见问题

**Q：启动报 `Incompatible mods found!`，说是别的模组需要更高的 Minecraft 版本？**
把 **Fabric Loader 升到 0.19.5 或更高**。在 0.19.3 及更早的 Loader 上，像 `gugle-carpet-addition`
这类"一个 jar 里内嵌多个 MC 版本"的包会被错误地解析成更高版本的子包，从而误报不兼容。这不是本模组引起的。

**Q：masa 的热键在哪里？**
在「类型 → 热键 → 目标」的选择界面里，左栏找 `Tweakeroo · 功能开关` 这类分类，或者直接搜索热键名。
它们不在原版「选项 → 控制」里，那是因为 malilib 用的是自己的热键表。

**Q：需要服务器也装吗？**
不需要。这是纯客户端模组，联机服务器没有它也能正常使用（轮盘只在你本地操作，不改变服务器判定）。

**Q：会不会和别的模组冲突？**
不会修改任何原版行为。唯一需要留意的是「原始按键」类型：它会把该键的完整事件注入游戏，
如果那个键在原版里还绑着别的功能，会被一并触发 —— 所以建议把原来的绑定解绑。
